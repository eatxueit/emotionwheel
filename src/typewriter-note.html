Typewriter Note

A note field that behaves like a sheet in a typewriter. The carriage moves to the next line on its own at the right margin, Return starts a new line, and you set your own margins and indents with the space bar and tab.

Clear this note? It can't be brought back.
Space One column forward
Tab Next tab stop, every 5 columns
Backspace Does nothing, no erasing
Return New line, twice for a blank line
